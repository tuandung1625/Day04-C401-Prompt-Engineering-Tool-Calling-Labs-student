# Tool: image_analyzer


## Chức năng
Công cụ `image_analyzer` cấp khả năng thị giác máy tính (Computer Vision) cho Agent. Nó nhận một đường link URL hình ảnh và một câu lệnh (query) để phân tích, mô tả hoặc trích xuất dữ liệu (như text, số liệu từ biểu đồ) bên trong bức ảnh đó.

## Yêu cầu
- Cần có `OPENROUTER_API_KEY` trong file `.env`.
- Đường dẫn `image_url` phải là một link ảnh có thể truy cập công khai.
