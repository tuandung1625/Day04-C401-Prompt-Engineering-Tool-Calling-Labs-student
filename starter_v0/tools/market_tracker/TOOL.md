# Tool: market_tracker

**Tác giả:** [Tên nhóm của bạn]
**Phiên bản:** 1.0

## Chức năng
Công cụ `market_tracker` giúp Agent tra cứu dữ liệu giá cổ phiếu, tiền tệ hoặc tiền điện tử theo thời gian thực (real-time). Rất phù hợp nếu Research Agent của bạn hướng tới việc nghiên cứu tin tức tài chính và xu hướng thị trường.

## Yêu cầu
- Không yêu cầu API Key bên thứ 3 (sử dụng API công khai).
- Yêu cầu tham số `symbol` là một mã giao dịch hợp lệ (ví dụ: AAPL, GOOG, BTC-USD).
