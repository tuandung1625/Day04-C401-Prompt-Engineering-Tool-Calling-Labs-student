# Research Agent Platform - UI/UX

Modern dark-themed dashboard for evaluating and monitoring AI tool-calling agents.

## ✨ Features

- **📊 Dashboard**: Real-time metrics, accuracy trends, pass/fail ratios, tool usage stats
- **🔍 Run Inspector**: Deep dive into individual evaluation runs with detailed failure analysis
- **🧪 Playground**: Interactive testing interface to run agent with custom queries
- **🛠️ Tools Explorer**: Visual catalog of all available tools with parameter docs

## 🚀 Quick Start

### 1. Install Dependencies

```bash
cd starter_v0
python3 -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt

# Install UI dependencies
pip install streamlit altair
```

### 2. Generate Evaluation Data

Before running the UI, you need run data:

```bash
# From starter_v0 directory
python run_eval.py \
  --provider openrouter \
  --version v0 \
  --suite base \
  --eval-cases data/eval_base.json
```

This creates run files in `starter_v0/runs/*.json`.

### 3. Launch the UI

```bash
# From project root
cd ..
streamlit run app/main.py
```

The UI will open at `http://localhost:8501`.

## 🎨 UI Components

### Dashboard Tab
- **KPI Cards**: Case accuracy, tool routing, argument accuracy, total cases
- **Accuracy Trend**: Line chart across versions (reads `version_log.csv`)
- **Pass/Fail Distribution**: Donut chart
- **Tool Usage**: Horizontal bar chart from actual run data
- **Failure Type Breakdown**: Color-coded failure categories
- **Version Comparison**: Grouped bar chart comparing v0, v1, v2, v3
- **Multi-turn Accuracy**: Single vs multi-turn performance

### Run Inspector Tab
- Run file selector (dropdown with all runs)
- Metadata display (version, provider, model, phase)
- Case-by-case results with:
  - Pass/fail badges
  - Actual vs expected tool calls
  - Failure details
  - Query input
  - Tool results (expandable JSON)
- Filter by Pass/Fail
- Search by case ID or skill

### Playground Tab
- Provider selector (openrouter, openai, anthropic, gemini)
- Optional model override
- Max tool rounds config
- Live query input
- Execution with real agent
- Display:
  - Assistant response
  - Tool calls (expandable)
  - Tool results (JSON)

### Tools Tab
- Grid layout of all registered tools
- Tool card with icon + name + description
- Expandable parameter details (required/optional, type, description)

## 🔧 Customization

### Add a New Chart

1. Create function in `app/components/charts.py`:
```python
def render_my_chart(data):
    df = pd.DataFrame(data)
    chart = alt.Chart(df).mark_bar().encode(...)
    st.altair_chart(chart, use_container_width=True)
```

2. Import and use in `main.py`:
```python
from components.charts import render_my_chart
# In a tab:
st.markdown("#### My Chart")
render_my_chart(my_data)
```

### Add a New Component

Create a new file in `app/components/`, e.g., `timeline.py`:

```python
import streamlit as st

def render_timeline(events):
    for event in events:
        st.markdown(f"**{event['date']}**: {event['text']}")
```

Then import in `main.py`.

### Modify Theme Colors

Edit `app/styles/main.css`:

```css
:root {
    --accent-primary: #FF6B6B;  /* Change accent color */
    --bg-primary: #1A1A1A;      /* Change background */
}
```

## 📊 Data Flow

```
run_eval.py → runs/*.json
                  ↓
            main.py (loads JSON)
                  ↓
        Components (visualize data)
```

The UI is read-only — it visualizes data but doesn't modify evaluation results.

## 🐛 Troubleshooting

### "No run files found"
- Run `python run_eval.py` first to generate data
- Check `starter_v0/runs/` directory exists and has `.json` files

### "No module named 'streamlit'"
```bash
cd starter_v0
source .venv/bin/activate
pip install streamlit altair
```

### Charts not rendering
- Ensure `pandas`, `altair` installed
- Check browser console for JavaScript errors
- Try `st.cache_data.clear()` button in sidebar

### CSS not loading
- Check `app/styles/main.css` exists
- Verify path in `main.py`: `CSS_PATH = Path(__file__).parent / "styles" / "main.css"`

### Agent playground errors
- Check `.env` file has API keys (`OPENROUTER_API_KEY`, etc.)
- Verify `starter_v0/artifacts/system_prompt.md` and `tools.yaml` exist
- Provider must be one of: `openrouter`, `openai`, `anthropic`, `gemini`

## 🎯 Usage Tips

1. **Always run eval first** to get baseline data before exploring UI
2. **Use version_log.csv** to track optimization experiments
3. **Playground is live** — it calls real APIs (costs tokens)
4. **Filter in Run Inspector** to focus on failures only
5. **Refresh data** button in sidebar reloads from disk
